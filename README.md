# python-study-automation

A collection of Python scripts that calculate math formulas and organize study files.

---

## 🛠️ Included Tools

### 1. File Organizer (`file_organizer.py`)
- **Purpose:** Automatically scans messy directories (e.g., Downloads folder) and organizes files into categorized subfolders (`Documents/`, `Images/`, `Code/`).
- **Concepts used:** Python `os` and `shutil` modules, loops, and file path manipulation.

### 2. Math Formula Calculator (`math_calculator.py`)
- **Purpose:** Solves routine geometry and algebraic equations (e.g., circle area, Pythagorean theorem).
- **Concepts used:** Mathematical operators, functions, and formatting.

---

## 🚀 How to Run

1. Ensure **Python 3** is installed on your computer.
2. Run either script directly from your terminal:
